# "Gitting" Started Class

A hands-on class for learning Git and GitHub fundamentals. Students practice core version control workflows including branching, committing, opening pull requests, and merging changes.

## What We Practice

- Creating and switching branches
- Making commits with meaningful messages
- Opening and reviewing pull requests
- Merging branches and resolving conflicts
